## 💻 Cara Menjalankan di Komputer Lokal

1. **Clone repositori:**
   ```bash
   git clone https://github.com/Y2riq/ariqfadhilahs.git
   cd ariqfadhilahs
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```

4. **Build untuk produksi:**
   ```bash
   npm run build
   ```

5. **Deploy ke GitHub Pages:**
   ```bash
   npm run deploy
   ```
